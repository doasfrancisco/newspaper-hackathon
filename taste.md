## Learned taste signals

Positive signals (like):
- Tools that connect to or work with AI agents (Claude Code, Codex, agent memory, agent proxies, agent harnesses). Strongest signal. The user is curious how they work under the hood.
- New AI tool launches from major players (X/Grok, Cursor) — first-hand usage reports count.
- New, concrete developer / programming tools with a clear mechanism (code analysis, terminal tools, motion editor, credential brokers). The user tries tools.
- Technical engineering breakdowns and write-ups (migrations, architecture, how-it-was-built posts with a blog link).
- Educational deep-dives on software internals (virtualization, KVM/QEMU/Firecracker, systems layers) — learning material with diagrams.
- Hardware products with real innovation (custom chips, AI hearing aid, robotics / physical AI). Product news counts when there is a concrete device.
- Practical AI-business content that helps the user's own AI factory.
- Open source / GitHub link is a plus.

Negative signals (skip):
- Funding, valuation, and VC news — even about AI/dev-tool companies (CodeRabbit, Lovable, Figma). The user likes the tool, not the money story.
- AI anecdotes without an artifact (Claude fixed my WiFi, agents complaining in Slack). Funny is not enough; there must be a tool or write-up to use.
- Politics and current-affairs commentary.
- Opinion, drama, or gossip about AI vendors.
- Venture fund, hiring, and brand marketing.
- Memes, jokes, and video-only posts.
- Personal life posts unrelated to tech.
